# Plan del Proyecto - IR-Assistant

## 1. Introducción
IR-Assistant es una aplicación web que busca asistir en la recuperación de información mediante técnicas de procesamiento y clasificación de texto. Este documento presenta el plan de trabajo del proyecto, de acuerdo con los lineamientos de ISO/IEC 12207.

## 2. Objetivos
- Implementar un prototipo funcional de un asistente web para recuperación de información.
- Asegurar calidad y seguridad del software mediante pruebas y buenas prácticas.
- Documentar el proceso de desarrollo y evidencias según ISO/IEC 12207.

## 3. Alcance
- Versión inicial como aplicación web con API de clasificación.
- No incluye aún interfaz gráfica avanzada ni despliegue en la nube productivo.

## 4. Cronograma
- **Semana 1:** Definición de requisitos y arquitectura.
- **Semana 2:** Implementación de módulos principales (procesamiento, clasificación).
- **Semana 3:** Pruebas, integración, seguridad (Bandit, pip-audit).
- **Semana 4:** Documentación final y entrega.

## 5. Roles
- **Miguel Espinoza** – Desarrollador y responsable de integración.
- Posibles revisores/profesores – Aseguramiento de calidad.

## 6. Herramientas
- Lenguaje: Python 3.10+
- Framework: Flask
- Control de versiones: GitHub
- QA: pytest, bandit, pip-audit, black
